# HASSAN Training — Safe Preview Rebuild

## الحالة
هذه نسخة استعادة/تجهيز مبنية على ملفات المنصة المحفوظة سابقاً، وليست نشر إنتاج.

- Worker الحالي: `hassantraining84`
- قاعدة D1 الحالية: `hassan-training-db-8`
- Binding: `DB`
- لا يتم إنشاء Worker أو D1 جديدين.
- لا توجد أوامر migrations في هذه الحزمة.
- لا يوجد DROP أو TRUNCATE أو حذف للجداول أو البيانات.

## حماية البيانات
القيمة الافتراضية `ALLOW_DB_WRITES=false`؛ لذلك تعمل واجهة الفحص والقراءة فقط. لا يتم حفظ التقييمات أو إتمام التمارين في D1 قبل التحقق من بنية الجداول الموجودة ومراجعة النتيجة.

## الفحص
بعد إعداد Preview فقط، افتح:
`/api/health`

يجب التأكد من:
- `database: true`
- `schema_ready: true`
- `write_enabled: false`

إذا ظهر `schema_ready: false` فلا تفعّل الكتابة ولا تشغّل أي migration. راجع أسماء الأعمدة والجداول أولاً.

## محتويات النسخة
- `public/index.html`: الواجهة الأصلية المستعادة مع ربط أفضل لحفظ التقييم واللوحة.
- `public/data/exercises.json`: مكتبة التمارين الثنائية اللغة المستعادة (150 سجلًا).
- `src/index.js`: واجهة API وفحص مخطط D1 مع وضع قراءة فقط افتراضياً.
- `wrangler.jsonc`: إعدادات Worker الحالي وD1 الحالية.

## تنبيه نشر
هذه الملفات على فرع معاينة مستقل. لا تغيّر فرع الإنتاج ولا تنشر هذه النسخة على Production قبل فحص `/api/health` ومراجعة توافق المخطط.
